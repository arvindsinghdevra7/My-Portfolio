## ⚡ React Project Kaise Run Karein (How to Run)

```bash
# 1. Dependencies install karne ke liye:
npm install

# 2. Local development server start karne ke liye:
npm run dev
# Browser me open karein: http://localhost:3000/

# 3. Production build generate karne ke liye:
npm run build
```
